POWERWISE CONNECT — STATIC WEBSITE

Files
- index.html: website content and page structure
- styles.css: responsive visual design
- script.js: small navigation interaction

Preview
Open index.html in a web browser. No build tools, account, framework or external image assets are required.

Upload / publish
1. Extract the ZIP file.
2. Upload the three files (or the extracted folder contents) to a static website host.
3. Make sure index.html is at the website root.
4. The website can be hosted on GitHub Pages, Netlify, Vercel static hosting, or a normal web host.

Important accuracy notes
- This is a concept website, not a live energy marketplace.
- Provider listings, live prices, payment processing, user accounts, energy monitoring and USSD/SMS are not implemented.
- No real providers, ratings, prices or customer results are claimed.
- The contact link uses a placeholder email address ending in .example; replace it with a real project email before publishing.

The website uses CSS illustrations and typography only. It does not rely on AI-generated images or external image libraries.
